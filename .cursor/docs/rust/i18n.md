# 后端 i18n（phpyun-rs）

原文：[phpyun-rs/docs/INTERNATIONALIZATION.md](../../../phpyun-rs/docs/INTERNATIONALIZATION.md)。

1. 接口 `msg` 必须是最终文案，不能把翻译 key 丢给客户端。
2. 固定文案：`phpyun-rs/locales/{en,zh-CN,zh-TW}.json`（编译期嵌入）。
3. 后台可改的分类/地区：库表 + 启动加载内存，不要请求时查字典表拼文案。
4. 语言顺序：`?lang=` → `Accept-Language` → Cookie `lang` → 默认。`en-US` 归一成 `en`。
5. 业务代码不要 `if lang == "en"` 拼字符串；走 i18n / 字典服务。
6. 翻译 key 要稳定，不要用中文原文当 key。

这和 PHP 模板 `{yun:}t key='wap_00439'` / `data/lang/auto/*.php` **不是同一套**。改 Nuxt 文案走 `web/` 的 i18n；改 Rust 报错走 `locales/` 与 `rust-i18n`。
