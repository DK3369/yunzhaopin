# 后端 i18n（phpyun-rs）

原文：[phpyun-rs/docs/INTERNATIONALIZATION.md](../../../phpyun-rs/docs/INTERNATIONALIZATION.md)。

1. 接口 `msg` 必须是最终文案，不能把翻译 key 丢给客户端。
2. 固定文案：`phpyun-rs/locales/{en,zh-CN,zh-TW}.json`（编译期嵌入）。**只补本接口用到的编号**，不要把 Vue 1.6 万 key 整包打进 Rust。
3. 后台可改的分类/地区：库表 `phpyun_dict_i18n` + 启动加载内存，不要请求时查字典表拼文案。
4. 默认 `en`。只有 cookie 选了 `zh` 才是中文（前台 `lang`，后台 `admin_lang`）。BFF 发给 Rust 的是单条 `Accept-Language: zh-CN|en`（cookie `zh` → 请求头 `zh-CN`）。不嗅探浏览器 `Accept-Language` 列表。页面和 `/api/proxy` 不要带 `?lang=`。Rust 的 `?lang=` 仅供 curl。磁盘目录仍是 `locales/zh-CN.json`、`cms-pages/zh-CN/`（内部名，对齐请求头 `zh-CN`）。
5. 业务代码不要 `if lang == "en"` 拼字符串；走 i18n / 字典服务。
6. 翻译 key 要稳定，不要用中文原文当 key。

## 四层（不要合成一套文件）

| 层 | 干什么 |
|---|---|
| Nuxt 编号包 | 按钮、表头、`lc()`。`web/apps/{admin,site}/i18n/locales/{zh,en}.json` |
| Rust `msg` / `*_n` 枚举 | 错误文案、支付方式、订单类型、支付状态等。码 → 编号 key → `enum_labels::label`（`current_lang()`） |
| `dict_i18n` | 职位/行业/地区/`comclass`/`userclass` 等运营可改分类名。英文岗名另有 bundled `data/job-en.json`；企业性质/规模/福利/简历标签等 bundled `data/{comclass,userclass,industry}-en.json`。库表优先，bundled 只补缺 |
| Packed | 库里历史 blob：套餐名、日志 `content`、`pay_remark`、前台导航名（key、中文或拼接）。`web/layers/base/app/utils/packedText.ts`，后台 `packedLog` / 前台 `runPackedTranslate`。后台登录日志 / 管理员操作日志 / 解绑 / 预警 / 短信日志的 Content **必须** `packedLog`；用户自写（简历、面试、留言、反馈、微信图文、异常原文）不要 packed。英文后台 `lazy` 不会加载 `messages.zh`，且 `zh.json` 会被 vue-i18n 编成 AST；`phpLc` 静态引入后抽叶子文案当 prefix 表 |
| CMS 单页 | `/get/:id` 标题与 HTML。`phpyun-rs/cms-pages/{zh-CN,en}/`：`meta.json`（页脚/左栏）+ `{id}.html`（正文）。后台首次保存生成、改完再覆盖。公开接口按 `current_lang()` 读文件，英文缺回退 `zh-CN`，文件都没有才回退主表（只读、不写盘）。**不要** `OnceLock` 灌全文，不要 Vue / Rust `locales/` 大 JSON，不要 `phpyun_cms_i18n` |

## 存什么

- **码/数字**：`company_order.order_type` / `type` / `order_state`。读时翻成当前语言。
- **运营配置中文**（套餐名、前台导航名/分类名 `phpyun_navigation`）：库保持原样，后台列表展示 `packedLog`。词条缺精确中文时在 `phpLc` extraZh 钉编号（找人才 / 企业库 / 积分商城等）。新写入尽量存编号 key（过期套餐 `admin_user_company_00297`）。编辑表单仍绑库里的中文，不要把翻译写回库。
- **系统日志**：新写入 `phpyun_login_log.content` 只存编号 key（WAP `common_06521`，PC `common_06522`；当日再登录 `wap_01557admin_tool_00738` / `admin_tool_00739`），禁止再拼中文「端口延续登录」。历史中文/拼接靠 packed + `phpLc` extraZh（`admin_tool_00738`/`00739`）。
- **不翻**：公司名、用户名、采集 JD、地址、管理员自由备注。

入口：[enum_labels.rs](../../../phpyun-rs/crates/products/recruit/services/src/enum_labels.rs)。getCache 的 `source` / `user_sex` / `com_sex`、SEO 模块名与变量名也走这里。广告位 `place_n`（非 PC/WAP 的「未定义」）、默认积分名、问答举报原因、采集 `last_msg` 同样走编号 key / `label()`，不要 `if lang` 拼句。

这和 PHP 模板 `{yun:}t key='wap_00439'` / `data/lang/auto/*.php` **不是同一套**。改 Nuxt 文案走 `web/` 的 i18n；改 Rust 报错与枚举标签走 `locales/` 与 `rust-i18n`。不改 `uploads/` PHP。

## 站内通知语言

面试 / 收藏 / 关注等写入站内信时硬钉 `Lang::ZhCN`（`NOTIF_LANG` / `WECHAT_LANG`），对齐 PHP。产品未拍板「永远中文还是跟当前请求语言」之前，**不要改**这些常量。

横切（me / SSR cookie / localeAsyncKey / 媒体 URL / settings 缓存）见 [cross-cut.md](./cross-cut.md)。
